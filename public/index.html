yt-dlp Required

This app requires yt-dlp to download videos. Install it with one command:

winget install yt-dlp

or with pip: pip install yt-dlp

For best quality merging, also install ffmpeg.

Settings

To download age-restricted or login-required videos, you need to export your browser cookies as a cookies.txt file.

⚠️ No cookie file uploaded

  1. Install the Get cookies.txt LOCALLY Chrome extension (or equivalent for your browser)
  2. Go to the site you want to download from and log in
  3. Click the extension icon → Export → saves a cookies.txt file
  4. Upload that file here using the button above

—

  • Age-restricted sites — Export cookies from your browser after logging in.
  • Private videos — Must be logged in before exporting cookies.
  • Fragment errors — Try a lower quality or refresh the page URL and retry.
  • Geo-restricted — Use a VPN to access content not available in your region.
  • Best quality — Install ffmpeg for merging best video + audio streams.

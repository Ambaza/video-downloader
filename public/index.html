yt-dlp Required

This app requires yt-dlp to download videos. Install it with one command:

winget install yt-dlp

or with pip: pip install yt-dlp

For best quality merging, also install ffmpeg.

Settings

Certains sites (ex. PornHub) renvoient une erreur 410 / 403 à yt-dlp car ils détectent qu'il ne s'agit pas d'un vrai navigateur. Pour les contourner, installez curl_cffi :

pip install -U "yt-dlp[default]" curl_cffi

Puis redémarrez l'application. (Rien à faire si c'est déjà actif.)

Les cookies permettent de télécharger du contenu restreint (âge, connexion requise). Le mode Auto extrait les cookies directement depuis votre navigateur — plus besoin d'exporter manuellement.

Sélectionnez le navigateur depuis lequel extraire les cookies. Utilisez celui où vous êtes connecté aux sites.

💡 Fermez votre navigateur avant de tester si vous rencontrez des erreurs DPAPI.

Au moment du téléchargement, les cookies de tous les navigateurs installés (Chrome, Edge, Brave, Firefox, Opera, Vivaldi) et de Tor sont fusionnés automatiquement.

⚠️ Chrome / Edge / Brave (v127+) chiffrent leurs cookies : ils ne sont lisibles que navigateur fermé, et pas toujours. Firefox et Tor fonctionnent même ouverts.

🧅 Tor : détection…

La solution la plus fiable : l'extension lit les cookies via le navigateur lui-même (aucun déchiffrement), même Chrome/Edge ouverts, cookies de connexion et d'âge inclus.

—

  • Contenu restreint — Activez le mode Auto et connectez-vous sur le site dans votre navigateur.
  • Erreur DPAPI — Fermez votre navigateur avant de télécharger, ou utilisez un fichier cookies.txt.
  • Fragment errors — Essayez une qualité plus basse ou rafraîchissez l'URL.
  • Geo-restricted — Utilisez un VPN.
  • Meilleure qualité — Installez ffmpeg pour fusionner vidéo + audio.
